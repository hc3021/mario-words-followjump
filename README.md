# 超级玛丽背单词 · 体感跳跃版

> 孩子对着摄像头真的跳起来，顶砖块答单词——把背单词变成一个会动的游戏。

**在线试玩**：`https://<你的用户名>.github.io/<仓库名>/`

## 玩法

1. 打开链接 → 允许摄像头 → 站到镜头前
2. 跳起来顶到飘过来的砖块
3. 砖块上的英文单词，下方四块砖是中文选项，撞对就得分
4. 连对 5 个触发连击奖励
5. 没有摄像头也能玩：按空格键或点角色起跳

## 内容

官方题库 300 词 / 10 个主题，面向 5-8 岁：
· 食物
· 动物
· 日常物品
· 身体部位
· 颜色形状
· 数字时间
· 家庭成员
· 衣物穿戴
· 学校教室
· 自然天气

## 技术要点

- 前端 Phaser 3 + Canvas，像素素材全部由 Canvas 程序化生成，无外部图片依赖
- 体感识别：MediaPipe Pose（lite 模型 2.8MB）全部资源本地化，跑在浏览器里，画面不上传不联网
- 防误触判定：肩和胯同时上移 + 脚踝离地 + 连续 3 帧，5 档灵敏度可调
- 学习闭环：漏答/答错的词自动进错词本，结算页可专项练，答对即划掉
- 进度自动保存（学到第几个 + 得分），重开可续
- 支持 Excel 导入导出自定义词库、语音朗读、速度 0.5–3.0× 调节
